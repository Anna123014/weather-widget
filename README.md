# 济南生活挂件 · Weather Widget

一个**单文件**的生活信息挂件：打开就有时钟、日期、济南实时天气，背景还会跟着天气和时间变化。

不需要安装、不需要构建、不需要 API Key——双击 `index.html` 就能用。

```
└──────────────────────────────┘
```

## 功能

| 功能 | 说明 |
|---|---|
| **时钟** | 精确到秒，每秒刷新 |
| **日期** | 年月日 + 星期，自动计算 |
| **实时天气** | 温度、天气描述、体感温度 |
| **穿衣建议** | 根据体感温度和天气状况给一句话建议 |
| **动态背景** | 晴 / 云 / 雨 / 雪 四种动画，各分白天、夜晚两套配色 |
| **日夜文字配色** | 夜间自动把文字转成浅色，保证看得清 |
| **自动刷新** | 天气每 30 分钟刷新一次，也可点按钮手动刷 |

## 技术说明

| 项目 | 说明 |
|---|---|
| 形态 | 单个 `index.html`，HTML + CSS + JS 全部内联，零依赖 |
| 天气数据 | [Open-Meteo](https://open-meteo.com/) 免费 API，**无需注册、无需 API Key** |
| 定位 | 经纬度写死在代码里（济南 `36.65, 117.12`），不申请浏览器定位权限 |
| 时区 | 固定 `Asia/Shanghai` |
| 动画 | 纯 CSS `@keyframes`，不依赖任何动画库 |

## 怎么用

**直接用**：双击 `index.html`，用 Chrome / Edge 打开。

**当桌面挂件**：浏览器里按 `F11` 全屏，或者用 Edge 的「安装为应用」功能固定到桌面。

**当浏览器主页**：把文件路径设为浏览器启动页。

## 已知小问题

- **农历是写死的**（`农历十月初一`），没有接农历库，不会自动变。要准的话需要引入 `lunar-javascript` 之类的库，或者改成只显示公历。
- 天气接口失败时只显示一句提示，需要手动点「刷新天气」重试。
- 需要联网才能拿到天气；离线时时钟和日期照常工作。
